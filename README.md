<h2>Findings</h2>
<p align="center">
 <br/>
 Ticket 1: Expired Password Lockout
 <br/>
 The password expired during a 3-week absence, and the login screen wouldn't let the user change it. I located her account in the Directory and issued a temporary password allowing her to login into her account and change her password once inside her account.
<p align="center">
<br/>
Ticket 2: Building-Wide Printer Outage
<br/>
The outage hit every printer in the building, so I checked shared infrastructure first and found PRINT01 was the only degraded server. A reboot restored printing, and the user confirmed the fix.  

<p align="center">
<br/>
Ticket 3: Department Transfer Access Change
<br/>
This was a planned access change. I added the user to the IT Infrastructure and removed her from Engineering, and she confirmed access to files and needed material for her new position.
